# Catatan keputusan teknis

ADR (Architecture Decision Record) menyimpan konteks, pilihan, alasan, dan konsekuensi keputusan yang berdampak pada proyek.

Belum ada ADR teknis yang disahkan. Gunakan [template keputusan](../../templates/keputusan-teknis.md), lalu simpan sebagai `0001-topik-keputusan.md` dan tambahkan tautan di sini.

Topik awal: stack produksi; model konten dan routing ID/EN; integrasi formulir; hosting, domain, dan pemulihan produksi. Topik yang saling bergantung boleh dibahas bersama, tetapi alasan setiap keputusan tetap harus jelas.

Status: Usulan → Disepakati → Digantikan bila ada keputusan baru. Catat pihak yang memutuskan dan tanggalnya. Keputusan lama tetap disimpan dengan tautan ke penggantinya. Keputusan bisnis yang sudah ada tetap merujuk ke [rancangan](../../rancangan-website.md).
